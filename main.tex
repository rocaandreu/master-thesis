% --- Thesis abstract.
%     For German thesis also provide an English version via the optional
%     argument: \abstract[English]{German}
\abstract{Applying forward error correction (FEC) to a live packet stream requires grouping packets from
the same flow into fixed-size generations before they can be encoded, which creates a mismatch
with how packets actually arrive at a network interface: individually, and interleaved across
many concurrent flows. This thesis presents the design and simulation-based evaluation of a
packet buffer that bridges this mismatch, implemented as an extension to the Open NIC Shell
targeting an AMD/Xilinx Alveo U55C. Following a shared-memory architecture, packet payloads are
stored in a single HBM-based memory pool shared across all flows, while each flow is tracked through a
small queue of packet addresses that a packet reader stage drains in complete generations for
the encoder. \\

The design was verified with a UVM-like testbench and, across a range of
packet sizes, flow-interleaving patterns, and configurations, sustains the data rate it is fed
from the host while keeping its own contribution to packet latency under
10 microseconds. Every major parameter of the design, including generation size, flow count,
and queue depths, is fully configurable, and its modular, stage-based structure is intended to
be easy to build on. The results also show that overall packet latency is largely governed by how
traffic is interleaved across flows rather than by the buffer itself, and point to
flip-flop usage and fixed elaboration-time configuration as the main directions
for future work.}
